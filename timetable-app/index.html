겨울방학 주간 시간표

아래 목록에서 '+ 추가'를 누른 수업만 시간표에 나타나요. 선택은 이 브라우저에 저장됩니다. 겹치는 시간은 빨간 테두리로 표시됩니다. 각 수업의 신청 상태(미신청·마감·신청중·신청완료)와 대기 번호는 직접 바꿀 수 있어요.

시간표 사진만 저장돼요. 표는 옆으로 밀어서 볼 수 있고, 수업 칸을 누르면 시간표에서 빠지고, 빈 칸을 누르면 자습·모의고사 같은 내 일정을 적을 수 있어요.

기기 간 동기화

토큰 만드는 법
  1. GitHub → 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access는 Only select repositories에서 timetable만 선택
  3. Permissions → Repository permissions → Contents를 Read and write로 설정
  4. 만든 토큰을 복사해서 위 칸에 붙여넣고 연결

저장소가 공개라서, 담은 수업과 신청 상태 파일(data/state.json)은 주소를 아는 누구나 읽을 수 있어요. 토큰은 이 기기 브라우저에만 저장되고 언제든 GitHub에서 폐기할 수 있습니다.

강좌 정보는 올려주신 겨울방학 강좌표 PDF(MEXX·미래탐구·새움·세정·대치명인)와 두각 예비고3 시간표 PDF, 수강신청 캡처를 합친 것입니다. 시간표는 요일·시간 기준 주간 반복이라, 개강일이 다른 수업끼리도 같은 시간이면 겹침으로 표시됩니다. 12/24 이전에 시작하는 단기 특강은 정규 수업과의 겹침 검사와 주간 합계에서 뺐습니다. 신청 상태는 처음에 모두 '미신청'이고, 각 수업에서 직접 바꾼 값만 저장됩니다.
