# 겨울방학 주간 시간표

겨울방학 강좌를 요일·시간대별로 담고, 겹침과 신청 상태를 관리하는 시간표 앱입니다.
크롬에서 주소를 열면 "앱 설치"로 설치할 수 있습니다.

| 폴더 | 내용 |
|---|---|
| [`timetable-app/`](timetable-app/) | 앱 (HTML, 서버 없이도 동작). GitHub Pages 로 배포 |
| [`server/`](server/) | (선택) 담은 수업·신청 상태·내 일정을 저장하는 작은 서버. Cloudflare Workers 로 배포 |

담은 내용은 기본적으로 **그 기기의 브라우저 안에만** 저장됩니다. 여러 기기에서 같은 내용을 보려면 서버를 올리세요.

## 앱 올리기
저장소 Settings → Pages → Source 를 **GitHub Actions** 로 → Actions 탭에서 **시간표 앱 배포** 실행 → 요약의 주소 열기.

## 서버 올리기 (컴퓨터 없이 휴대폰으로, 한 번만)
GitHub 가 대신 올려 줍니다(`.github/workflows/server.yml`). 비용은 무료(Cloudflare Workers 무료 범위)입니다.
서버는 **한 번만** 만들면 모두가 같이 씁니다.

1. **Cloudflare** https://dash.cloudflare.com 가입 → 왼쪽 메뉴 **Workers & Pages** 를 한 번 열어 두기 (무료 주소 `○○.workers.dev` 가 이때 만들어짐)
2. 같은 화면의 **계정 ID**(Account ID) 복사
3. 오른쪽 위 사람 아이콘 → **내 프로필 → API 토큰 → 토큰 생성 → "Cloudflare Workers 편집"(Edit Cloudflare Workers) 템플릿 → 사용** → 계정 리소스에 내 계정 선택 → 요약 계속 → 토큰 생성 → 복사 (한 번만 보여요)
4. **GitHub** 이 저장소 → Settings → Secrets and variables → Actions → **New repository secret** 으로 아래 2개 넣기
   (휴대폰에서는 브라우저 메뉴의 "데스크톱 사이트"를 켜면 Settings 탭이 보여요)

   | 이름 | 값 |
   |---|---|
   | `CLOUDFLARE_API_TOKEN` | 3번 토큰 |
   | `CLOUDFLARE_ACCOUNT_ID` | 2번 계정 ID |
5. 저장소 **Actions** 탭 → **시간표 서버 배포** → 가장 위 실행 → **Re-run all jobs**
6. 끝나면 실행 화면 아래 요약에 **서버 주소**가 나와요.
7. 시간표 앱 맨 아래 **기기 간 동기화**에 서버 주소와 **내 코드**(예: `0310손서영`)를 넣고 **저장 시작**.

## 내 코드란?
- 사람마다 **자기 코드**를 정해서 앱에 적으면, 그 코드로 담은 수업·신청 상태·내 일정이 서버에 저장됩니다. 따로 가입은 없어요.
- 같은 코드를 적은 다른 기기에서는 같은 시간표가 보이고, 코드가 다르면 완전히 다른 시간표입니다.
- 코드는 4글자 이상, 한글도 됩니다. 코드를 아는 사람은 그 시간표를 볼 수 있으니 **남이 알기 어렵게** 정하세요. (생일+이름만으로는 같은 반 친구가 맞힐 수 있어요)
- 서버에는 코드 자체가 아니라 암호화한 값(SHA-256)으로만 저장 칸을 구분합니다. 코드를 잊으면 같은 내용을 다시 볼 수 없어요.

### 서버가 하는 일
| 주소 | 하는 일 |
|---|---|
| `GET /health` | 연결 확인 |
| `GET /state` | 내 코드로 저장된 시간표 데이터 (`X-App-Key` 헤더에 코드) |
| `PUT /state` | 내 코드로 시간표 데이터 저장 (최대 약 300KB) |

- 데이터는 Cloudflare Durable Object(SQLite)에 코드마다 한 칸씩 따로 저장됩니다.
- 앱 주소(`https://ssea3030g-debug.github.io`)에서 온 요청만 받고, 같은 주소에서 1분에 30번까지만 요청할 수 있습니다(`server/wrangler.toml`).
- 같은 코드를 두 기기에서 동시에 바꾸면 나중에 저장한 쪽이 이깁니다.
- 처음 쓰는 코드로 연결하면 그 기기의 내용이 저장되고, 이미 내용이 있는 코드로 연결하면 서버의 내용을 불러옵니다(그 기기의 현재 내용은 덮어써져요).
